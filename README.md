# ADA-GameHub-JavaScript Project

![GameHub](gamehub.png)

A JavaScript-powered e-commerce website for video games, built
as part of my frontend development studies at Noroff.

## Description

- Fetch API to retrieve live product data from the Noroff API
- Filter functionality to narrow down the product listing
- Add to cart and remove from cart functionality
- Cart state managed and persisted across pages
- Clean and consistent layout across 4 pages

## Built with

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Noroff Games API

## What I Learned

- Learned how to fetch and handle data from a real API using
  the Fetch API and async/await
- Understood how to manipulate the DOM dynamically to render
  product cards from API data
- Built search and filter functionality from scratch, learning
  how to work with arrays and JavaScript methods like filter()
  and includes()
- Learned how to manage cart state across multiple pages
- Developed confidence in debugging JavaScript and reading
  error messages to understand what was going wrong
- Learned how to use AI as a learning tool — not just to fix
  problems but to understand them

## Future Improvements

If I were to continue developing this project, I would focus on:

- Improving the visual design and UI to match a more polished
  look and feel
- Adding localStorage so the cart persists when the page is
  refreshed
- Adding a checkout page with form validation
- Writing cleaner, more modular JavaScript by breaking
  functions into separate files
- Adding loading states and error handling for API failures
